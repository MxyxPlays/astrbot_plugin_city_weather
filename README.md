# 城市天气（高德天气 API）

**全国城市都能查**（省 / 市 / 区县，精确到县级市），不用记斜杠指令，**直接说人话**就行。

比如 `上海天气`、`北京天气预报`、`杭州西湖天气`、`温州瑞安天气`、`明天广州天气`。

## 一、怎么用

在群里或私聊直接发：

```
温州瑞安天气
上海天气怎么样
北京天气预报
明天杭州天气
后天上海天气
瑞安市气温
天气 上海
/天气 上海
```

只发「天气」两个字 → 查配置里的默认城市。

### 支持的说法

| 想查什么 | 这么说 |
| --- | --- |
| 当前实况 | `温州瑞安天气`、`上海天气怎么样`、`上海气温` |
| 未来几天 | `北京天气预报`、`上海未来几天天气` |
| 只看明天 | `明天杭州天气`、`杭州明天天气` |
| 只看后天 | `后天上海天气` |
| 默认城市 | `天气`、`/天气` |

闲聊不会被误触发：`天气真好`、`今天天气不错` 这种会照常交给大模型聊天。

## 二、回复长什么样

实况（一条）：

```
🌤 瑞安市 天气
──────────
天气：多云
气温：26℃
湿度：86%
风力：东风 ≤3级
──────────
🕐 更新 18:35
```

预报（**一条消息，按天分行**）：

```
📅 温州市 天气预报
──────────
今天(10-18 周日) 多云转晴 24-34℃
明天(10-19 周一) 晴 24-33℃
后天(10-20 周二) 晴 25-34℃
大后天(10-21 周三) 多云转晴 18-27℃
──────────
🕐 更新 21:35
```

如果想要「每天单独弹一条」，把配置里的 `forecast_split` 打开即可。

> 温度区间写成 `24-34℃` 而不是 `24~34℃`，是因为 AstrBot 的「分段回复」
> 会把 `~` 当断句符号，`24~34℃` 会被切成「24~」和「34℃」两条消息。
> 同理，插件发出的文本里不要出现 `。 ？ ！ …`。

问「明天」时只发那一天：

```
📅 上海市 明天（10-19 周一）
──────────
白天：小雨 24℃
夜间：多云 22℃
风：东北风 1-3级
```

> 温度区间写成 `24-31℃` 而不是 `24~31℃`，是因为 AstrBot 的「分段回复」
> 会把 `~` 当断句符号，`24~31℃` 会被切成「24~」和「31℃」两条消息。


## 三、配置项

| 键 | 说明 | 默认 |
| --- | --- | --- |
| `amap_api_key` | 高德 Key（服务平台必须是**Web服务**） | 空 |
| `default_city` | 只发「天气」时查哪里 | 上海 |
| `forecast_split` | 预报每天单独弹一条（默认关闭：一条消息里分行） | 关 |
| `only_when_woken` | 群里是否必须 @ 或唤醒才回 | 关 |
| `show_source` | 末尾是否显示「分隔线 + 🕐 更新 21:47」 | 开 |
| `timeout` | 请求超时（秒） | 20 |

## 四、想改的话

代码里三个正则就是全部的识别逻辑（`main.py` 顶部）：

```python
SUFFIX_PATTERN   # 城市+天气：杭州西湖天气
PREFIX_PATTERN   # 天气+城市：天气 上海
EXACT_PATTERN    # 只有「天气」
```

比如你想支持「上海冷不冷」，就在 `SUFFIX_PATTERN` 的结尾加上：

```python
r"(?:预报|怎么样|咋样|如何|情况|怎样|冷不冷|热不热)?"
```

改完在面板里**重载插件**即可，不用重启 AstrBot。

## 五、常见问题
**Q：说「天气」没反应？**
群里如果开了 `only_when_woken`，需要 @机器人。默认是关的，看到就直接回。
**Q：报 10001 / 10009（Key 无效）？**
Key 的『服务平台』选错了。必须是「Web服务」，选成 Web端(JS)/Android/iOS 都会报无效。
**Q：报 10023 / 10003？**
免费额度用完了。目前来看高德天气接口个人开发者每月有免费额度，用完要等次月 1 号重置，或在控制台提额。
**Q：查不到某个镇/街道？**
天气接口最细只到区县一级。
